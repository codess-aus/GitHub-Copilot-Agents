# A guide to GitHub Copilot agents

From your first custom agent to reliable, governed workflows: explore **28 illustrated chapters**, one clear step at a time.

Start with the foundations, learn how to shape an agent's work, then connect those ideas to planning, validation and human oversight.


## Read your way

Use the chapter tiles below, the chapter list, or search. Each chapter has **Previous**, **Home** and **Next** navigation at the bottom. The last chapter leads to Resources.

Switch between light and dark mode using the control in the header. The site uses a locally hosted Atkinson Hyperlegible font, generous line spacing, left-aligned text and restrained reading surfaces. Font preferences vary; no single font works best for every reader.
